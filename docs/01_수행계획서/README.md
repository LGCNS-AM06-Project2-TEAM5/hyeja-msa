# 01 수행계획서

팀·주제·일정·역할을 1페이지 수준으로 정리합니다. 1차 양식을 그대로 씁니다. 아래는 양식에 옮겨 쓸 내용입니다.

## 주제

청년 주거 정책 추천 서비스 「혜자」(미니프로젝트 1)를 마이크로서비스로 나누고, 서비스 사이를 Feign·Kafka로 연결하고, 컨테이너로 배포합니다. 기능을 새로 만들기보다 완성된 서비스를 나누고 연결하는 데 집중했습니다.

## 일정

| 마일스톤 | 날짜 | 한 일 |
|---|---|---|
| Day 1 · 설계 | 10-30(금) | 서비스 분리 기준, MSA 설계서, 저장소·협업 규칙 |
| (주말) | 10-31 ~ 11-01 | 서비스 4개 기본 구성, Eureka·Config·Gateway 골격 |
| Day 2 · 골격과 분리 | 11-02(월) | 1차 코드를 서비스별로 옮기고 DB 3개로 분리 |
| Day 3 · 통신 연결 | 11-03(화) | OpenFeign F1~F6, Kafka 이벤트, Docker Compose 통합 실행 |
| Day 4 · 핵심 기술과 통합 | 11-04(수) | 서킷 브레이커, 모니터링, CI/CD, 관리자 운영 화면, EC2 배포, 통합 검증 |
| Day 5 · 제출과 발표 | 11-05(목) | 산출물 제출(오전 9시), 발표 |
