## 화면설계서

화면은 1차 혜자를 그대로 쓰고, 이번에 관리자 운영 화면을 더했습니다. 화면설계서 파일은 아직 이 폴더에 없습니다.

## 시연 영상 (5분, 필수)

제작 중입니다. 완성되면 링크를 여기에 적습니다. 시연 순서는 아래와 같습니다.

1. 전체 구조 (Gateway → 서비스 4개, DB 3개, Eureka·Config, Kafka)
2. 로그인과 Gateway JWT 검증
3. 맞춤 홈과 카드뉴스 (F6)
4. AI 맞춤 검색 (F1·F2·F3)
5. 정책 상세 자격 판정과 관심 표시 (F6·F4)
6. 관심 등록 (F5)
7. Eureka 대시보드
8. 관리자 운영 화면, user-service를 멈춘 뒤 서킷 브레이커 대체 응답과 자동 복구
9. Kafka 이벤트 동기화와 DLT
10. Grafana, Zipkin
11. GitHub Actions CI/CD, EC2 배포
